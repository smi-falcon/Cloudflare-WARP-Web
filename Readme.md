### Deploy with Vercel

Разверните свою копию проекта в один клик:

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/smi-falcon/Cloudflare-WARP-Web&repository-name=cloudflare-warp-web)

Или используйте Vercel CLI:

1. Установите CLI: `npm i -g vercel`
2. Выполните команду в корне проекта: `vercel deploy`

Для локальной разработки запустите:
`vercel dev`
